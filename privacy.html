隐私政策 (Privacy Policy)

更新时间：2026年1月1日 · 保护用户数字隐私是我们一切技术架构的最高原则

1. 严正承诺：不保留任何用户使用日志 (Strict No-Logs Policy)

🛡️ 我们的核心承诺：您在 Strong VPN 管道内的数据只属于您自己

Strong VPN 从网络架构底层贯彻严格无日志政策（No-Logs Policy）。我们在任何情况下都绝不记录、绝不监控、绝不存储、绝不转售您的任何在线网络使用足迹。

具体而言，我们在服务器端绝不收集或保存以下任何信息：

  • 网页浏览与访问历史：绝不记录您访问过的任何网站、API 请求或应用程序交互；
  • 传输数据与内容：绝不解析或留存任何在加速隧道中传输的明文数据、通信记录或下载文件；
  • 用户源 IP 与出口 IP 绑定：绝不记录您的真实物理 IP 地址以及被分配的出口节点 IP 对应关系；
  • DNS 解析查询：所有 DNS 请求均通过私有专属加密 DNS 服务器在 RAM 中实时处理，绝无解析日志落盘；
  • 连接与会话时间戳：绝不记录您的连接时长、断开时间或具体网络会话时间戳。

2. 全 RAM 内存纯净架构保障

传统的网络代理服务器常使用硬盘存储系统文件与缓存，可能存在日志落盘风险。Strong VPN 的全球节点机房全面部署了纯 RAM（内存）易失性系统。

服务器不搭载传统数据持久化硬盘，一旦服务器发生物理断电或重启，内存中的所有运行态瞬时数据将在硬件层面彻底瞬间物理销毁，从物理根源上彻底阻断任何第三方技术取证或数据泄露的可能。

3. 最小必要信息收集与使用范围

为了向您提供基础的账户管理、支付结算与防滥用机制，我们仅在用户注册与购买时收集以下极其有限的数据：

  • 账户身份凭证：用于登录的电子邮件地址（支持使用任何匿名加密邮箱服务如 ProtonMail）以及经不可逆加盐哈希（Argon2id）加密后的密码。
  • 订阅与支付凭证：购买的套餐类型、过期时间以及第三方支付网关生成的匿名订单流水号（我们绝不触碰或存储您的任何银行卡号、信用卡安全码等敏感财务信息）。
  • 总体流量计量计数：仅用于按月统计您所购套餐的剩余流量配额，该计数器为纯数字统计，不包含任何流量来源或去向细节。

4. 传输加密与第三方豁免

您与我们节点之间建立的所有连接均强制采用国际公认的高强度加密通道（AES-256-GCM、ChaCha20-Poly1305），杜绝公共 Wi-Fi 中间人劫持或运营商嗅探。

我们绝不会向任何第三方数据经纪商、营销广告联盟或商业机构出售、出租、交换用户的任何注册数据。

5. 用户权利与彻底清除

根据全球隐私保护规范（包括 GDPR 等相关标准），您拥有对其账户数据的完全控制权。您可以随时在个人中心申请一键注销账户并永久清除所有注册关联信息。
